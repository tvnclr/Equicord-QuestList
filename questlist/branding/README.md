# QuestList branding

- `symbol.svg`: the symbol, white on transparent, on the 108 × 108 icon grid.
- `icon.svg`: app icon, the symbol on a black rounded tile.
- `QuestList.ico`: Windows icon built from `icon.svg` (16, 20, 24, 32, 40, 48, 64, 128 and 256 px).
- `icon-512.png`: `icon.svg` at 512 px.
- `banner.png`: README banner, 1024 × 500.

Accent color: Red, `#FF8E86` on dark surfaces and `#C0282D` on light ones.
